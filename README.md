Projeto Big Data - Real Gesso

Projeto desenvolvido para aplicação de conceitos de Big Data utilizando dados reais da empresa Real Gesso.

Estrutura do projeto
projeto_bigdata_real_gesso/
├── dados/
│   └── .gitkeep
├── scripts/
│   └── .gitkeep
├── docs/
│   └── .gitkeep
├── .gitignore
└── README.md
Pastas
dados/: arquivos e bases de dados utilizados no projeto.
scripts/: códigos utilizados para tratamento e análise dos dados.
docs/: documentos e materiais relacionados ao projeto.
Arquivos
.gitignore: define arquivos e pastas que não devem ser enviados para o Git.
README.md: apresenta informações e instruções sobre o projeto.
Controle de versão

O projeto utiliza Git para controle de versão e GitHub para armazenamento do repositório e colaboração entre os integrantes da equipe.
